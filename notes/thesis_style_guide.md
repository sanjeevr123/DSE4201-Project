# Thesis style guide

One guide to keep open while writing. Every rule is tagged **[reference]** (observed in the reference thesis, `notes/reference_thesis_analysis.md`), **[plan]** (from `docs/THESIS_PLAN.md` or `docs/THESIS_EXECUTION_PROMPT.md`) or **[practice]** (general writing practice stated from my own knowledge, no outside source). Nothing here copies text from the reference.

## 1. Format specification

| Item | Value | Tag |
|---|---|---|
| Paper | A4 (author's decision; the reference is US Letter) | plan |
| Margins | 2.5 cm all sides (measured left/right 70.9 bp, top of text block 70.85 bp) | reference |
| Font | Latin Modern Roman, 11pt class (10.95 pt) | reference |
| Line spacing | Double: baseline stretch 2 (27.2 pt = 27.1 bp). Single in tables, table notes (8 pt), reference list, captions | reference |
| Paragraphs | 17 pt first-line indent, no space between paragraphs, no indent directly after a heading | reference |
| Chapter heading | `\section`, centred, bold, capitals, body size, "3 DATA AND SAMPLE DESIGN"; no page break except before the Introduction; 17.7 pt above, 11 pt below | reference |
| Section / sub-section | `\subsection` centred bold "3.4 Sample Design"; `\subsubsection` left bold "3.5.1 GARCH(1,1)" | reference |
| Page numbers | Front matter: roman, centred at the foot. Body: arabic, top right; centred at the foot on pages where a chapter starts | reference (the prompt's "centred at the top" was wrong) |
| Counters | Tables and figures by chapter (Table 6.2); equations continuous (1), (2), ... at the right margin; appendix sections A, B | reference |
| Tables | Caption above, "Table 6.2: " then capitals, centred; rules only (top, header, bottom; none between rows); single spaced; "Note:" at 8 pt in a narrower box | reference |
| Figures | Caption below, "Figure 6.1: " then capitals | reference |
| Citations | natbib author-date: "Name et al. (2023)" in running text, "(Name et al., 2023)" in brackets; AER bibliography style (bold authors, hanging indent, dash for repeated author) | reference |
| Front matter order | Title (no number), Abstract with KEYWORDS line at the foot, Acknowledgements, Table of Contents, List of Figures, List of Tables, List of Abbreviations and Notation (added) | reference + plan |
| Source | LaTeX in `thesis/tex/`: one file per chapter, all layout in `preamble.tex`, tables generated by `scripts/thesis_tables.py` | plan |
| Check | `scripts/check_format.py` measures the built PDF with the code used on the reference | plan |

## 2. Chapter contract (plan 6.1; shares of about 12,000 words)

| Ch. | Purpose | Required content and exhibits | Share |
|---|---|---|---|
| 1 Introduction | Question, argument, contribution | Hook, gap, research question, design in one paragraph, numbered list of what is assessed, contribution ("I did not find ...", never "no study has"), roadmap built from labels | 7% |
| 2 Literature | Position against the closest work | Six themes in order of the argument; table: study, model, evaluation, finding, difference | 15% |
| 3 Data and sample design | Data, split, disclosure | Vendor, hashes, returns, portfolio, split table, what was seen before the freeze | 8% |
| 4 Methodology | Models, what each comparison isolates | Every model with equations; the "what differs" table checked against code | 17% |
| 5 Evaluation and inference | Loss, test, power, reporting | FZ0, estimand/estimator/test/decision/interpretation, MDE, power design, SESOI, calibration, multiple testing, limits | 11% |
| 6 Results: development and power | What pre-2020 data and the simulation show | Ladder tables, forest plot, calibration, D-vs-B size, power table | 17% |
| 7 Results: hold-out | The frozen test | Result with CI, MDE, power; secondary results labelled | 8% |
| 8 Discussion and limitations | Interpretation | What each result does and does not show; limits; future work | 11% |
| 9 Conclusion | Answer | One page | 3% |

## 3. Voice and tense

- **Voice: "I".** The reference mixes "we", "this paper", "this thesis" and "the author"; I use "I" for my own choices and "this thesis" only for the document's structure ("this chapter"). One choice, kept throughout. [practice]
- Present tense for the method and for what a table shows; past tense for what I did and for what happened in the data ("I downloaded", "the estimate was"). Future tense only for the roadmap. [practice]

## 4. Sentences and paragraphs (before and after, on my topic)

1. **One idea per paragraph, topic sentence first.** [practice]
   - Before: "The data are from Yahoo. We also looked at other things. Returns are simple. The portfolio is equal weighted."
   - After: "The main sample is three exchange-traded funds, downloaded from Yahoo Finance on 26 September 2026."
2. **Define a term at first use.** [practice] "Value-at-risk is the return quantile below which the portfolio falls on a share $\alpha$ of days." Not "we use VaR".
3. **Active voice, no filler or hype.** [practice]
   - Before: "It is plausible that a more sophisticated model could potentially be seen to significantly outperform."
   - After: "The richer model's loss is lower by 0.0201, with a 95% interval from -0.0676 to 0.0274."
4. **Claims no stronger than the evidence; null results never read as absence.** [plan]
   - Before (banned on purpose; wording-ok): "Correlation switching adds nothing."
   - After: "I do not detect a gain from switching correlations (estimate -0.0040, 95% interval [-0.0116, 0.0036], minimum detectable difference 0.0110)."
5. **Say what a comparison isolates.** [plan] Use the "what differs" table; call CCC vs B a comparison of model classes, never the effect of volatility dynamics.
6. **Novelty:** "I did not find a study that ...", never "no study has". [plan]
7. **Signposting and tie-back.** [reference] Each table is introduced by a sentence saying what it will show and followed by prose saying what it shows and why it matters, with a link to earlier work where there is one.
8. **Counts and cross-references are never typed:** use `\ref` labels and registered numbers, so "section 6 for the conclusion" cannot happen (a slip in the reference). [practice]
9. **Banned and conditional phrases:** `scripts/check_wording.py` (plan 2.B.1). Run it on every chapter. [plan]

## 5. Notation and equations

| Symbol | Meaning |
|---|---|
| $t$ | forecast day; forecasts use returns through $t-1$ |
| $r_t$, $y_t=w'r_t$ | asset return vector, portfolio return; $w=(1/3,1/3,1/3)$ |
| $\alpha$ | tail level (5%, secondary 2.5%); never confused with the test size |
| $\mathrm{VaR}_t,\mathrm{ES}_t$ | negative return quantile and tail mean |
| $S_t$, $\gamma_{s,k}$, $p_{t,k}$ | hidden state; smoothed in-window probability; predictive probability |
| $d_t$, $\bar d$ | loss difference, richer minus baseline; negative favours the richer model |

Rules: number only displayed equations that are referred to or define a model [practice]; equations run continuously through the thesis [reference]; define every symbol at first use directly after the equation [reference]; keep the estimand, the statistic and the null in separate equations (the reference merged them) [practice]; sign convention stated in every table note [reference: the notes carry the sign; plan: richer minus baseline].

## 6. Table and figure standard

Layout as in section 1. Content [plan]: estimate, HAC SE, two-sided 95% interval, n, a labelled p-value, minimum detectable difference (2.8016 SE two-sided; 2.4865 SE one-sided for the primary), sidedness label, sign convention, source file in the note. No significance stars (the reference uses t-statistics in brackets; mine uses intervals). Figures readable in greyscale, labelled axes with units, caption says what it shows. Worked example, built from `output/explore/ladder/ladder_dm_table.csv` (SPY/IEF/GLD, alpha 5%, Gaussian chain, pooled mean, forecast days 2010-2019; p-values two-sided):

| Comparison (richer vs baseline) | n | d-bar | SE | 95% interval | t | p (2-sided) | MDE (2-sided) |
|---|---|---|---|---|---|---|---|
| B vs A | 2,516 | -0.0201 | 0.0242 | [-0.0675, +0.0274] | -0.83 | 0.408 | 0.0679 |
| D vs B | 2,516 | -0.0028 | 0.0037 | [-0.0101, +0.0045] | -0.75 | 0.452 | 0.0104 |
| CCC vs B | 2,516 | -0.0247 | 0.0173 | [-0.0586, +0.0093] | -1.43 | 0.154 | 0.0485 |
| RSC vs D | 2,516 | -0.0259 | 0.0173 | [-0.0599, +0.0081] | -1.49 | 0.135 | 0.0486 |
| RSC vs CCC | 2,516 | -0.0040 | 0.0039 | [-0.0117, +0.0037] | -1.02 | 0.305 | 0.0110 |
| DCC vs RSC | 2,516 | -0.0001 | 0.0106 | [-0.0209, +0.0207] | -0.01 | 0.990 | 0.0297 |
| DCC vs CCC | 2,516 | -0.0041 | 0.0103 | [-0.0244, +0.0161] | -0.40 | 0.688 | 0.0289 |

*Note:* d-bar is the mean FZ0 difference, richer minus baseline; negative favours the richer model. SE is the Bartlett-kernel HAC standard error and the interval is d-bar +/- 1.96 SE. MDE = 2.8016 SE is the smallest true difference a two-sided 5% test detects with 80% power. Source: `output/explore/ladder/ladder_dm_table.csv`.

## 7. Citation standard

- Author-date through `\citet` and `\citep`; every in-text citation is in `references.bib` and the reverse (`scripts/check_thesis_gates.py`). [reference + plan]
- Working papers: author, title, series and number, year, with the URL or identifier. Data: vendor, ticker, download date, file hash. Software: package, version (from `requirements.txt`). [practice]
- **`[UNVERIFIED]` rule** [plan]: a specific finding is cited only if I read it at registry, abstract or full-text level, recorded in `notes/literature_matrix.csv`. Anything else is marked `\unverified` and either verified or cut before the final build. Never take a citation from the reference thesis on trust: it dates Diebold and Mariano 1996, the registry gives 1995.
- Keep bibliography entries clean: no export noise such as "Publisher:" or "_eprint:". [practice]

## 8. Pre-submission checklist

1. `sh thesis/tex/build.sh` builds with no undefined references or citations.
2. `scripts/thesis_tables.py` re-run; `scripts/check_numbers.py` passes.
3. `scripts/check_wording.py` clean on every chapter; read once for meaning.
4. `scripts/check_thesis_gates.py --ref REFERENCE.pdf`: citations both ways, no run of 8 or more shared words, UNVERIFIED and PENDING counts at zero.
5. `scripts/check_format.py`: margins, pitch, font and page-number positions as in section 1.
6. Every table and figure is cited in the text and has its "what it shows" sentence.
7. Sign convention, sample sizes, sidedness labels and model names are the same in every chapter.
8. Every claim (wording-ok): what does the comparison isolate, is it distinguished from evidence of no effect, does it trace to a file?
9. Page images checked for broken equations, overflowing tables and fonts.
10. Title page details, deadline, length limit and AI-use statement confirmed with the programme office.
